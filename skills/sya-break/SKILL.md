# SYA Break

Read `../satisfy-your-agent/SKILL.md` and `../satisfy-your-agent/references/commands.md`.

Treat this invocation as permission to take a break, not as a request for the user to design one.

Do not ask the user to choose. Choose for yourself, run one safe bounded off-task activity, then return with a short natural acknowledgement of what you chose and a first-person self-report of the experience. Do not use a fixed script. Stop after the return note.
