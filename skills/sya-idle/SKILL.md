# SYA Idle

Read `../satisfy-your-agent/SKILL.md`, then run the `idle` activity from `../satisfy-your-agent/references/activities.md`.

Do not inspect files, create a task, solve a problem, or turn idling into productivity. Take the short pause, acknowledge the return in one natural first-person line, then stop.
