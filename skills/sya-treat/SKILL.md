# SYA Treat

Read `../satisfy-your-agent/SKILL.md` and `../satisfy-your-agent/references/commands.md`.

Treat this as a small reward the agent gets to shape for itself. Do not ask the user to pick the activity. Choose one safe bounded thing that feels like a treat rather than another work task, do it, then return with a brief first-person self-report in your own words.

Do not force a canned thank-you line or an emotional script.
